# Каталог: откуда берутся товары

## Основной путь — бесплатно, напрямую с thepoizon.ru
```bash
node scripts/scrape-poizon.mjs --pages 3     # ~28 подкатегорий, ~2900 товаров, ~2 мин
git add data/catalog.json && git commit -m "catalog: обновление" && git push
```
Страницы категорий thepoizon.ru отдают в `__NEXT_DATA__` готовый JSON (60 товаров
на страницу, `?page=N`). Каждый понедельник то же самое делает GitHub Action
`.github/workflows/catalog.yml` — цены на сайте не старше недели.

## Цены
Формула одна на весь сайт — `lib/pricing.ts`: цена источника → юани по нашему
курсу → +15% наценки → валюта страны, округление вверх. Цена источника —
минимальная по размерам, поэтому на сайте она «от». Доставка считается в
корзине по тарифам @po1zoncalculator_bot и весу категории.

## Запасной путь — Apify (платно)
Если thepoizon.ru снова закроется анти-ботом:

```bash
export APIFY_TOKEN=...            # уже есть в ~/.zshrc
node scripts/refresh-catalog.mjs --per 40     # 7 категорий × 40 = до 280 товаров
git add data/catalog.json && git commit -m "catalog: обновление" && git push
```
`--dry` покажет план и стоимость, ничего не потратив.

## Сколько это стоит

|---|---|
| Цена за товар | $0.002 |
| Бесплатный лимит Apify | $5 в месяц |
| Товаров на бесплатный лимит | ~2500 |

## Почему так устроено
- **Источник — актор Apify `piotrv1001/poizon-listings-scraper`.** Прямой парсинг
  thepoizon.ru умер: сайт отвечает «Security Verification» и HTTP 429 и на Node,
  и на настоящий браузер. Актор ходит через прокси-пул и возвращает разобранные
  поля: название, артикул, цену в рублях, картинку, число продаж, дату релиза.
- **Каталог лежит файлом `data/catalog.json` в репозитории.** Раньше он хранился
  в Vercel KV. KV закрыли, переменные окружения из проекта исчезли, и витрина
  молча стала отдавать пустой список — сайт показывал только запасные карточки.
  Файл в гите так сломаться не может и не требует ни одной переменной окружения.
- **Обновление не сокращает витрину.** Скрипт сливает новый прогон со старым
  файлом по `id`, поэтому категория, которая в этот раз не ответила, не пропадает.

## Если понадобится больше товаров
Платный тариф Apify — $39/мес, это порядка 19 500 товаров. При каталоге больше
примерно 5000 позиций файл стоит заменить на Vercel Blob: JSON в несколько
мегабайт уже неудобно держать в гите и тащить в бандл.
